# Security Policy

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue, pull request, discussion, or support ticket.

Use the repository's private security advisory form:

https://github.com/ZiyadAhmed910/Fortress-of-Muslim/security/advisories/new

Include the affected URL or component, reproduction steps, expected impact, and any request ID returned by the platform. Do not include live API keys, OAuth client secrets, access tokens, passwords, private keys, or personal data. Revoke any credential that may have been exposed before sending the report.

## Supported Releases

The latest release on `main` is the supported production version. The `dev` branch and `*-test.fortressofmuslim.org` services are beta environments and may change without compatibility guarantees.

## Scope

Security reports may cover the PWA, API, Auth Worker, MCP gateway, Developer Portal, Admin Console, Status Portal, deployment workflows, and repository configuration. Content corrections and source-verification concerns belong in the normal editorial issue workflow rather than the security channel.
